{% comment %} ATRUE per-tab context bootstrap (shared by base.html and dashboard_base.html). Cookies are SHARED by every tab in the browser, so a cookie alone cannot describe "who is signed in on THIS tab". Each tab therefore keeps a random, non-secret selector in sessionStorage and ships it with every request: * ?ctx=... full page navigations (links, back/forward, refresh) * X-ATRUE-CTX header fetch() / XMLHttpRequest * hidden ctx field form posts (incl. Enter key and submit()) The token is a lookup key only. It carries no credentials, and the server re-derives request.user, roles and permissions from the session it points at, so a forged or stale token can never escalate access. Two rules matter for correctness: 1. The ?ctx= parameter is deliberately KEPT in the address bar. A full page request cannot carry a custom header, so the query string is the only transport that survives a manual refresh and a back/forward navigation. Stripping it (as an earlier version did) silently logged tabs out on refresh. 2. sessionStorage is CLONED when a tab is duplicated or opened from a link, while window.name is not. If a token is present but this document has no matching window.name marker, the tab is a copy, so it gets a brand new token and reloads BEFORE the body renders. The server gives it a private workflow session and may inherit only the source tab's account identity. {% endcomment %}
