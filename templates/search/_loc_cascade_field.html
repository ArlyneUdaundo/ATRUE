{% comment %} Reusable inline cascading Country → Region → Province → Municipality/City → Barangay dropdown group. Powered by static/js/location-cascade.js (window.ATRUE_LOC_DATA / /locations/api/). Region narrows the province list. It only submits where a model actually stores a region (pass `region_name`); otherwise it carries no `name`, needs no column on any model, and a province belongs to exactly one region anyway, so the saved province already determines it. Barangay is Philippine only. GeoNames has no barangay level outside the Philippines, so for every other country the JS hides the whole Barangay group and clears its value, ending the cascade at Municipality/City. Only one Barangay control is ever active (pick-list or free-text fallback) so a single `name` always submits. Country is a select whose value is the Country NAME (persisted to the model's country column); the JS resolves it and can reload the whole tree for any foreign country on demand. Pass `include_country=False` to omit it.
